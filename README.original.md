# 作业小助手 HomeworkBot v3.3

在后台接收 QQ 班级群消息 → 找出老师布置的作业 → AI 整理成统一格式 → 按日期存档 → 推送到企业微信群。
**v3.0 起不再需要打开 QQ / 微信窗口**：QQ 消息通过 NapCat 接收，推送通过企业微信群机器人 Webhook 完成，可以完全在后台运行。

```
QQ 班级群 ──> NapCat(小号登录, OneBot v11) ──WebSocket/HTTP──> 作业小助手 ──Webhook──> 企业微信群
                                                        │
                                                        └─> AI 整理 / 存档 / 历史
```

## 一、你需要准备的
1. **一个 QQ 小号**（推荐，不要用主号），并让它加入孩子的班级 QQ 群。
2. **NapCat**：一个免费开源的 QQ 机器人框架，在后台登录 QQ 小号，不需要打开 QQ 窗口。
3. **企业微信群 + 群机器人 Webhook 地址**（企业微信的“消息推送”，旧称“群机器人”）。
4. （可选）大模型 API Key，推荐 DeepSeek（https://platform.deepseek.com ）或通义千问。不填时用内置规则整理。

## 二、安装作业小助手
- **推荐**: 运行 `HomeworkBot-Setup-3.3.0.exe` 安装(无需管理员权限), 自动创建开始菜单和桌面快捷方式。
- 直接使用打包好的 `HomeworkBot\HomeworkBot.exe`（整个文件夹一起复制）；或
- 源码运行：安装 Python 3.9+，双击 `run.bat`（首次自动安装依赖）。
- 自己打包：双击 `build_exe.bat`（无人值守：`build_exe.bat nopause`），生成 `dist\HomeworkBot\HomeworkBot.exe`。

## 三、配置 NapCat（QQ 接收）
1. **下载**：打开 https://github.com/NapNeko/NapCatQQ/releases ，下载 `NapCat.Shell.Windows.OneKey.zip`（一键版，自带 QQ），解压后运行 `NapCatInstaller.exe`，完成后进入 `NapCat.xxxx.Shell` 目录。官方文档：https://napneko.github.io/guide/boot/Shell
2. **扫码登录**：双击 `napcat.bat`，用手机 QQ（小号）扫描窗口里的二维码。以后可用 `napcat.bat 小号QQ号` 快速登录。
3. **打开 WebUI**：控制台会显示 WebUI 地址和 token（一般是 http://127.0.0.1:6099/webui ），浏览器打开登录。
4. **网络配置**（三选一，推荐第一种）：
   | 方式 | NapCat 中新建 | 作业小助手中设置 |
   |---|---|---|
   | 反向 WebSocket（推荐） | “WebSocket 客户端”，URL 填 `ws://127.0.0.1:8095/onebot/v11/ws`，消息格式 Array | 连接方式选“反向 WebSocket”，端口 8095 |
   | 正向 WebSocket | “WebSocket 服务端”，端口如 3001 | 选“正向 WebSocket”，地址 `ws://127.0.0.1:3001` |
   | HTTP 上报 | “HTTP 客户端”，URL 填 `http://127.0.0.1:8096/`；如需“测试连接”再建一个“HTTP 服务端”端口 3000 | 选“HTTP 上报”，端口 8096，NapCat HTTP 接口 `http://127.0.0.1:3000` |

   如果在 NapCat 里填了 token，作业小助手的 access_token 要填一样的。
5. 在作业小助手“QQ/NapCat 连接”页点 **测试连接**，显示“当前登录 QQ: 小号”即成功。左下角圆点变绿表示已连接。

## 四、配置企业微信推送
1. 在企业微信里建一个群，把家人拉进来（群机器人只能加到企业微信内部群，家人需要用企业微信；个人也可以免费创建一个企业/团队）。
2. 群聊右上角 `···` → **消息推送**（群机器人）→ 添加 → 新建，复制 Webhook 地址（`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...`）。
3. 粘贴到“企业微信推送”页，每行一个，可写成 `名称|地址`，支持多个群。
4. 点 **测试推送**，群里收到测试消息即成功。
> Webhook 地址相当于密码，不要发给别人或公开。每个机器人限 20 条/分钟。

## 五、使用指南
| 页面 | 作用 |
|---|---|
| 仪表盘 | NapCat 连接状态与离线横幅、最近消息相对时间、今日作业卡片(科目色标/附件芯片/复制/重试)；开始/停止/重新连接、测试连接、推送今日汇总 |
| 作业历史 | 按日期、科目、关键词、状态搜索；查看原文和图片、编辑后重新推送、导出 Markdown/CSV/TXT |
| QQ/NapCat 连接 | 连接方式与端口、token、群号、老师（QQ 号/昵称/群名片）、作业关键词、相似去重、存档目录、原图保存；内置 NapCat 配置向导 |
| 企业微信推送 | 多个 Webhook、markdown/text 格式、是否推送图片、推送前确认/全自动、孩子名字与问候语模板、每日汇总；测试推送 |
| AI 设置 | 服务商一键选择、base_url/Key/模型、重试次数、可编辑提示词、测试 AI 整理 |
| 日志 | 实时日志（同时写入 `data/homeworkbot.log`） |
| 关于 | 开机自启、托盘、通知；配置导入/导出(可脱敏)；重新打开首次向导 |

- **推送前确认（默认）**：发现作业后弹窗显示整理结果，可修改后点“推送到企业微信”，也可稍后在仪表盘/历史里推送或忽略。
- **全自动推送**：发现后直接推送，失败自动重试，最终失败弹通知，并在历史里标记“推送失败”可重推。
- **老师识别**：填 QQ 号最准确；也可以填“王老师”，群名片或昵称包含即匹配。老师发的图片总会保留（下载原图，一并推送）。
- **后台运行**：默认启动即最小化到托盘并自动开始监听；配合“开机自动启动”即可无人值守。NapCat 断开会自动重连/等待重连，并弹通知。
- 消息模板变量：`{greeting}` `{child}` `{content}` `{date}` `{subject}`。

## 六、数据文件
- `config.json`：全部设置（v1/v2 配置自动迁移通用项）
- `data/history.db` 作业历史；`data/seen.json` 去重记录；`data/homeworkbot.log` 日志
- `<保存文件夹>/2026-10-15.md`：按日期存档；`attachments/<日期>/` 老师发的原图

## 七、注意与限制
- NapCat 属于非官方 QQ 客户端，存在被风控/封号的可能，**请务必使用小号**；NapCat 需保持运行和在线。
- 只能收到 NapCat 运行期间的新消息，离线期间的群消息不会补收。
- QQ 图片/文件/视频链接有时效，程序收到消息后会立即下载到 `attachments/`；下载失败时仅保存文字。
- 企业微信群机器人只能推送到企业微信群（不能直接推送到个人微信群）；markdown 在微信插件中的显示可能简化，可改用 text 格式。
- **企业微信不支持原生视频消息**：≤20MB 的视频会改作「文件」发送并附带说明；更大的视频只保存在本地，并在推送正文中注明文件名与路径。
- 图片消息 ≤2MB（超限自动压 JPEG；仍超限则改作文件发送）。普通文件/语音 ≤20MB（AMR 语音 ≤2MB 可用 voice 类型）。单条 markdown 最长 4096 字节、text 2048 字节，超长自动分条。
- 每个机器人限 **20 条/分钟**（含文字、图片、文件），程序内置滑动窗口排队。
- API Key、Webhook、token 以明文保存在 `config.json`，请勿外传。
